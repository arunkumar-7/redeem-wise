## 1. Purpose

This document defines the complete user interface flows, screen layouts, and navigation structure for the RedeemWise web application. It serves as the primary reference for frontend development and UX design.

---

## 2. Application Structure

### 2.1 Navigation Layout

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  Logo    Dashboard    Cards    Rewards    Recommendations    [Profile] [Logout]
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│                           Main Content Area                                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 Screen Inventory

| Screen | Route | Description |
|--------|-------|-------------|
| Login | /login | User authentication |
| Register | /register | New user registration |
| Dashboard | /dashboard | Main overview screen |
| Card List | /cards | Manage credit cards |
| Card Form | /cards/new, /cards/:id/edit | Add/edit card |
| Reward List | /rewards | View reward points |
| Reward Form | /rewards/new, /rewards/:id/edit | Add/edit rewards |
| Redemption Options | /options | View redemption catalog |
| Recommendations | /recommendations | View recommendations |
| Profile | /profile | User profile management |

**Login Flow Steps:**

| Step | Action | Result |
|------|--------|--------|
| 1 | User enters email and password | Form validated |
| 2 | User clicks Login button | API call to /api/auth/login |
| 3 | API returns JWT token | Token stored in localStorage |
| 4 | User redirected to Dashboard | Dashboard loaded |
| 5 | Error occurs | Error message displayed |

## 11. Form Validation States

### 11.1 Input Field States

| State | Visual | Description |
|-------|--------|-------------|
| Default | Border: gray | Normal state |
| Focus | Border: blue, shadow | User clicked/focused |
| Success | Border: green, ✓ icon | Valid input |
| Error | Border: red, ✗ icon | Invalid input |
| Disabled | Gray background | Non-editable |

### 11.2 Validation Messages

| Message Type | Example | Color |
|--------------|---------|-------|

| Format | "Invalid email format" | Red |
| Min Length | "Password must be 8 characters" | Red |
| Match | "Passwords do not match" | Red |
| Success | "Looks good!" | Green |
